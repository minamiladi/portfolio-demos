# Portfolio demos

Demo projects with fictional businesses, made as portfolio samples. Nothing here is a real company, and no form sends anything. Every page is marked `noindex`.

- `ai-assistant/`: a car rental site (fictional "Sanbouk Drive") with its Arabic + English assistant. The answers are recorded word for word from the real model test run (Groq, gpt-oss-120b); typing is off, and the live version runs on the client's own server.
- `booking/`: a physiotherapy clinic (fictional "Larkspire Physiotherapy") booking page. Free times come from the app's own slot engine; the payment step is a demo (no real payment, no card fields), and a "behind the scenes" box shows what the CRM and analytics would receive.

Live: https://minamiladi.github.io/portfolio-demos/
