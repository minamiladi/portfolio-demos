# AI assistant demo (Arabic + English)

Demo project: a portfolio sample. "Sanbouk Drive" is a fictional car rental company in Jeddah; it is not a real company.

- The website pages are the client's demo site with the assistant widget.
- The widget replays answers recorded in the real test run (Groq, model openai/gpt-oss-120b), word for word, with their sources.
  Typing is off in this demo; the live version runs on the client's own server, which keeps the AI key.
- The call-back form sends nothing here; it shows the e-mail the sales team would get, with the mobile masked.
- Phone numbers are placeholders. Every page is marked noindex.
